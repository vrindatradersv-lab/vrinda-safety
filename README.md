## 🛡️ About VRINDA

**VRINDA Safety Solutions** is a manufacturer and bulk supplier of certified personal protective equipment (PPE) and industrial safety solutions across India:
- **Head & Face Protection**: ISI-marked safety helmets (Ratchet & Nape types), face shields, spectacles.
- **Body & Fall Protection**: Full-body harnesses, sit harnesses, lanyards, rope grabs, and retractable fall arresters.
- **Safety Footwear**: High-ankle and low-ankle steel-toe safety shoes, puncture-resistant midsoles, and combat boots.
- **High-Visibility Workwear**: Industrial coveralls, reflective surveyor safety jackets, and high-visibility gloves.
- **Lockout / Tagout (LOTO)**: Circuit breaker lockouts, valve lockouts, safety padlocks, hasps, and lockout stations.
- **Road & Parking Safety**: Traffic cones, speed bumps, rebar caps, road studs, solar blinkers, and wheel stoppers.
- **Safety Nets & Fire Safety**: Debris safety nets, border rope nets, and ISI-certified fire extinguishers.

## 🚀 Key Features

- **153 Catalog Products**: 100% 1:1 image and specification fidelity with studio-grade photography.
- **Interactive Product Explorer**: Instant search by product code/name and tabbed category filtering.
- **Direct WhatsApp RFQ**: Pre-filled quotes and product inquiries routed directly to the sales desk.
- **Direct Bulk Call**: Click-to-call direct contact for corporate procurement and tenders.
- **Mobile-First Responsive Design**: Optimized micro-interactions and compact UI for high-speed browsing on mobile and desktop.

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/vrindatradersv-lab/vrinda-safety.git

# Navigate to the project directory
cd vrinda-safety

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
# Build static production bundle
npm run build
```

The optimized static production files will be output to `dist/`.
